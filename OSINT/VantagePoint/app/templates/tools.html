Environment Capabilities & Routes

Syntax: POST:/path for POST, || to chain, {val|filters} for encoding.

Route Cheat Sheet

Methods: Prefix with POST: to change from default GET.

Chaining: Use || to query multiple endpoints for one IoC.

Filters:

  • {val|base64}: Standard Base64
  • {val|vt_id}: VirusTotal URL ID format
  • {val|sha256}: Hash the input

Example (VirusTotal URL):
POST:/urls || /urls/{url|vt_id}
Submits the URL, then fetches the report using the encoded ID.
